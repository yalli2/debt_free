# ZERO MOMENTUM · 제로 모멘텀
**빚을 0으로, 삶에는 가속을 — 3M(Mindset · Math · Momentum) 블루프린트**

다인에듀(다인원격평생교육직업학원) HR 분야 성인 대상 Debt-Free 프로그램 사이트입니다.
교재 *Debt-Free Blueprint: Crush Debt Fast on Any Income* (Nora's Creations)의 흐름을 따라 16개 챕터로 구성했습니다.

## 페이지
| 파일 | 내용 |
|---|---|
| `index.html` | 프로그램 홈 · 3M 지도 · 챕터 목록 · 방 참여 |
| `lesson.html?ch=0~15` | 챕터별 실습 (체크리스트·워크시트·시뮬레이터·계산기·배경화면 만들기·선언문 인증서 등) + 실시간 공유 활동 |
| `dashboard.html` | 나의 부채 대시보드 (부채 목록, 완납 예정일, 잔액 로드맵, 완납 타임라인, 전략 비교, 색칠 상환 차트, 비상금 게이지, 결제일 달력, 상환 기록, 월별 계획표, 마일스톤) |
| `board.html` | 강사 라이브 보드 (방 코드·QR 생성, 챕터별 응답 실시간 차트) |

## 수업 진행
1. 강사: `board.html` → **새 방 만들기** → QR을 화면에 띄우고 챕터 선택
2. 수강생: QR/링크로 접속 → 닉네임 입력 → 해당 챕터 실습, 투표·퀴즈·포스트잇 응답
3. 응답은 강사 보드와 모든 수강생 화면에 실시간으로 모입니다.

## 데이터와 개인정보
- 개인 부채 금액, 워크시트, 대시보드 데이터는 **각자의 브라우저(localStorage)에만** 저장됩니다. 대시보드의 내보내기/가져오기(JSON)로 기기를 옮길 수 있습니다.
- 실시간 공유 응답(투표·퀴즈·포스트잇·닉네임)만 공개 중계 서비스 [ntfy.sh](https://ntfy.sh)를 통해 전달되며 12시간 뒤 사라집니다. 수업마다 새 방을 만들어 사용하세요.
- ntfy.sh 무료 사용에는 IP당 일일 전송 한도가 있어, 수강생 전원이 같은 와이파이(같은 공인 IP)를 쓸 때 한 번에 너무 많은 챕터를 진행하면 일부 응답이 전송되지 않을 수 있습니다.
